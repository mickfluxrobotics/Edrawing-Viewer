eDrawings Viewer (version 9)

Opens eDrawings (.easm, .eprt), STEP, STL and 3MF models in 3D, and DXF and DWG drawings in 2D.
All files sit in one folder so GitHub's "choose your files" picker can upload them.
Upload every file to the repository root and commit; GitHub Pages republishes in a minute or two.

Third-party parts, each under its own licence (see the LICENSE files):
- three.js (MIT), fflate (MIT)
- occt-import-js and OpenCascade (LGPL-2.1) for STEP
- dwgdxf / acadrust (MIT) for DWG
- Hershey single-stroke font (free to use) for DXF/DWG text
